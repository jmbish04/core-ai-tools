The rule

A single stage transform — scale and translate — is owned by the comparison, not by either image. Both layers are absolutely positioned at inset:0 of the same box. Nothing can scale one side alone; there is no per-image fit.

What degrades, and when

By node count

1–10Rotation ±4°, captions on, 130px prints, full grain.
11–20Rotation ±2.5°, captions truncate to one line, 108px prints.
21+Rotation ±1.7°, captions off, 88px prints, grain at half.

By zoom

<70%Captions and count badges hide; pins shrink to 9px.
<50%Yarn filter drops to a plain stroke; shadows flatten to one layer.
<35%Grain off, rotation to 0. The board becomes a map you navigate.

Never degrades

Thread colour — relationship stays readable at every size.
The retry stack — it is the thing that keeps 30 nodes from being 60.
Pin colour for approval and drift states.
Computed layout. Free-arrange, if it ships, is a separate view with its own stored positions.

Cost

The displacement filter runs on one grouped path element, not per edge, and the grain is two static rects — both cheap. Rotation is the expensive one at scale because it defeats subpixel text caching, which is the real reason captions go first.
